# Home Assistant

Smart-home integration with one-click sign-in (OAuth)

Read the Home Assistant guide, then apply for an OAuth client so your users connect with one click.

## Build an integration

Maintaining an open-source integration (Home Assistant or anything else)? Apply for an OAuth client: your users sign in with one click and get their own key, activated instantly for the markets we approve for your integration.

One client per integration (GitHub repository), owned by one developer account. We review each application by hand before a client ID is issued.

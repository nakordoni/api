# Integrations built on our API

Community and partner projects that bring Nakordoni data into the tools people already use. Each one uses per-user API keys — and integrations approved for OAuth connect with one click and activate instantly.

## Connect Nakordoni to your apps

- **Telegram**: Ready posts in your channel — no code — https://nakordoni.eu/en/developers/integrations/telegram

- **Home Assistant**: Smart-home integration with one-click sign-in (OAuth) — https://nakordoni.eu/en/developers/docs/poi-opinion

- **Website / widget**: Show our data on your page or embed a widget — https://nakordoni.eu/en/developers/docs

- **Mobile app**: Android or iOS app — https://nakordoni.eu/en/developers/docs

- **Server API**: Server-to-server, data not shown to end users — https://nakordoni.eu/en/developers/docs

- **Make** (Soon): Scenarios with ready blueprints

- **n8n** (Soon): Workflows with a ready import file

- **Zapier webhook** (Soon): Send events to a catch-hook webhook

- **RSS** (Soon): A feed link for any RSS reader

- **Other**: Something else — tell us about it — https://nakordoni.eu/en/developers/docs

## Build an integration

Maintaining an open-source integration (Home Assistant or anything else)? Apply for an OAuth client: your users sign in with one click and get their own key, activated instantly for the markets we approve for your integration.

- Apply for an integration client: https://nakordoni.eu/en/developers/integrations/manage

- Sign up free: https://nakordoni.eu/en/developers/signup
